## 🚀 About Me

I am a **Software & AI Engineer** specializing in building, optimizing, and deploying production-grade AI systems and high-throughput backend architectures. My work spans from low-level GPU kernel optimization and self-hosted LLM inference to autonomous multi-agent systems and resilient microservice infrastructures.

- 🧠 **AI Engineering & LLM Ops:** Experienced in fine-tuning, quantizing, and serving open-source Large Language Models (such as **Qwen 2.5**, Llama, etc.) using **vLLM** and **Docker** on dedicated cloud GPU instances.
- ⚡ **Low-Level Compute & MLOps:** Working closely with **PyTorch**, **CUDA parallel computing**, and **Triton** for memory and latency optimization, alongside automated training and experiment tracking pipelines with **MLflow**, **XGBoost**, and **Random Forest**.
- 🤖 **Multi-Agent Systems:** Architecting autonomous agentic workflows utilizing **LangGraph**, **Model Context Protocol (MCP)**, and **Agent-to-Agent (A2A)** communication protocols.
- 🏗️ **Scalable Backend & Microservices:** Designing event-driven, fault-tolerant backend services using **NestJS**, **Go (Golang)**, **Node.js**, **PostgreSQL**, and **Redis Pub/Sub**.
- 📊 **Production Observability & Reliability:** Implementing end-to-end infrastructure monitoring with **Prometheus** and **Grafana**, and resolving complex production mobile/backend crashes, native thread call stacks, and ANR issues using **Sentry**.

## 🔥 Core Engineering Highlights & Projects

### 1. 🤖 Multi-Agent AI Lead Generation & Automation Engine
- **Architecture:** Engineered a multi-agent system leveraging **LangGraph**, **Model Context Protocol (MCP)**, and **Agent-to-Agent (A2A)** communication for automated B2B lead discovery, intelligent scraping, and outreach orchestration.
- **Backend Infrastructure:** Built a resilient **NestJS** backend containerized with **Docker**, featuring environment-driven dynamic rate-limiting (`ThrottlerModule`), extended LLM timeout handling, and parallel API processing.

### 2. ⚡ High-Performance LLM Serving, Fine-Tuning & Quantization
- **Inference Optimization:** Deployed quantized open-source LLMs (including **Qwen 2.5**) on cloud GPU clusters using **vLLM** and **Docker** for high-throughput, low-latency token generation.
- **Low-Level Kernel Exploration:** Utilized **CUDA** thread hierarchy optimization, memory coalescing techniques, and **Triton** alongside **PyTorch** to maximize hardware utilization.

### 3. 📈 End-to-End MLOps & Automated Retraining Pipelines
- **Experiment Tracking:** Designed automated monthly model training and evaluation workflows using **MLflow**, comparing ensemble architectures like **XGBoost** and **Random Forest** with versioned model registries.

### 4. 🔭 Microservices Observability & Mobile Production Reliability
- **System Telemetry:** Implemented full-stack observability for Dockerized **Go**, **Node.js**, and **PostgreSQL** microservices using **Prometheus** metrics scraping and real-time **Grafana** dashboards behind **Nginx** and **PM2**.
- **Production Debugging:** Managed high-availability mobile releases on Google Play, utilizing **Sentry** for deep thread stack analysis, memory profiling, and resolving Application Not Responding (ANR) bottlenecks.
